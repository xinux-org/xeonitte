## Development

This application has Linux-only dependencies.
```bash
# download dependencies
nix develop

# Generate configuration file
just setup

# Build
just install

# Run
# Avoid pkexec must be root error on devShell
just run

# Or one time build.
nix build --show--trace

# Optional. Generate translation words from /po/POTFILES.in if needed.
cd ./po
xgettext --directory=.. --files-from=POTFILES.in --from-code=UTF-8 -kgettext -o translations.pot
```

> All ./config folder data will be generated by meson after `nix build`. The code searchs for files from ~/.local/etc/xeonitte so you have to remove this folder and `just install` to update them.
